Checks are dispatched continuously based on your plan interval (down to 30 seconds on Business or 1 minute on Pro). The moment an HTTP request returns an error code (4xx, 5xx), a connection timeout, or a missing keyword, an alert is queued immediately through your configured channels (Email, Discord webhook, or custom webhook).
Sometimes a web server returns an HTTP 200 OK status code even when an application crashed (e.g., a database connection error page or maintenance screen). By providing a keyword like "Welcome" or "Add to Cart", Cheetah Uptime scans the response body to ensure your real application is actively rendering. If the string is missing, it marks the monitor as down.
